# SEKAI — неофициальный фан-сайт

Красочный адаптивный одностраничный сайт по **HATSUNE MIKU: COLORFUL STAGE!**.

## Что внутри

- Интерактивный первый экран и краткое знакомство с игрой.
- Пять музыкальных юнитов с переключением описания.
- Галерея из восьми скриншотов со страницы игры в Google Play, с фильтрами и просмотром на весь экран.
- Небольшая музыкальная мини-игра (клавиши A, S, D, F).
- Адаптивная верстка для смартфонов и ПК.

Всё работает на обычном HTML, CSS и JavaScript **без сборки, библиотек и серверной части**. Основной файл — `index.html`.

## Публикация

Для публикации через GitHub Pages используется workflow `.github/workflows/pages.yml`.

На GitHub откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**. При необходимости репозиторий должен быть публичным (для GitHub Free). После включения Pages сайт будет доступен по адресу:

https://kat151599.github.io/sekai/

## Скриншоты и авторские права

Скриншоты загружаются из Google Play, не копируются в репозиторий. При отсутствии доступа к Google Play CDN изображения могут не загрузиться. Источник: https://play.google.com/store/apps/details?id=com.sega.ColorfulStage.en

Это фанатский учебный проект, **не официальный сайт**. Игра и её материалы принадлежат соответствующим правообладателям, включая SEGA, Colorful Palette и Crypton Future Media. Не используйте материалы в коммерческих целях без разрешения правообладателей.
